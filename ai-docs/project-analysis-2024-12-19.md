## 项目核心发现

### 技术架构
- **前端**: React 18 + TypeScript + Vite
- **样式**: Tailwind CSS + shadcn/ui 组件库
- **国际化**: react-i18next 支持中英文
- **状态管理**: TanStack Query + React Hook Form
- **路由**: React Router DOM

### 设计特色
- **复古报纸风格**: 独特的视觉设计语言
- **响应式设计**: 移动端和桌面端适配
- **多语言支持**: 完整的中英文界面
- **组件化架构**: 高度模块化的代码组织

### 功能模块
1. **首页**: 邮件订阅 + 用户推荐展示
2. **导航**: 品牌标识 + 菜单 + 语言切换
3. **期刊系统**: 最近期刊展示 (待完善数据层)
4. **搜索功能**: 键盘快捷键支持 (待实现)

## 开发规范总结

### 代码风格
- TypeScript 严格模式
- ESLint 代码质量检查
